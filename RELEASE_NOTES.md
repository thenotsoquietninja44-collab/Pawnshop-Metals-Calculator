First Windows version of Pawnshop Metals Calculator.

- Silver, gold and platinum selling quotes using APMEX widget ask or bid.
- Silver defaults to spot + 25%; gold and platinum default to 0% until configured.
- Fine-content bullion and gross-weight jewelry modes; grams, troy ounces and pennyweights.
- Exact currency arithmetic, half-up cent rounding, and quantity totals based on rounded unit prices.
- Saved shop rules, manual spot override, five-minute refresh, and stale-price protection.
- Automatic GitHub update checks and downloads, with restart when convenient.

Download the Setup EXE below and install it. This initial installer is unsigned.
Settings are stored in the Windows user profile and preserved by subsequent updates.
