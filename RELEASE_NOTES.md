Coin catalog and shareable shop setups.

- 18 editable coin presets, including American Silver Eagles, Morgan and Peace dollars, Walking Liberty halves, silver quarters and dimes.
- Edit each coin's weight, purity and premium independently. Add, duplicate, remove and save custom coins.
- Choose spot plus a percentage OR spot plus a dollar amount per coin.
- Display the full equation, fine grams, troy-ounce conversion, melt value, rounding and quantity total.
- Export saved coin catalogs and shop rules to JSON. Import on another shop computer with replace/merge preview and a backup of the prior setup.
- Preserve existing settings and migrate older installations to a starter coin catalog.
- Keep APMEX widget pricing, stale-price protection and automatic GitHub updates.

Existing users can choose Check for updates in the app. New users can download the Setup EXE below. The installer is unsigned.
Settings are stored in the Windows user profile and preserved by subsequent updates.
